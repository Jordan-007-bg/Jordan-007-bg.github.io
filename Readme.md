
# Моето портфолио

Личен уебсайт, създаден с HTML и CSS.
В него представям себе си, моите умения и пет проекта.

## Какво поисках от AI

**1. Какво искам:**
Искам превъртането между секциите на портфолиото да бъде плавно.

**2. С какво работя:**
Използвам HTML и CSS във VS Code.

**3. Какво вече имам:**
Имам HTML страница с навигационно меню,
секции „За мен“, „Проекти“, „Умения“ и „Контакти“,
както и външен CSS файл.

**4. Какво не искам:**
Не искам JavaScript, допълнителни библиотеки
или сложно решение.

## Използвани технологии

- HTML
- CSS
- Git и GitHub
